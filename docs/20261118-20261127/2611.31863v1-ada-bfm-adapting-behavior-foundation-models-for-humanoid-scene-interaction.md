## 摘要
行为基础模型（BFMs）通过在大规模行为数据上进行预训练，已成为通用人形控制的一种有前景的范式。然而，它们在全身协调方面的能力并不能轻易扩展到场景交互，因为场景交互需要使运动适应依赖于场景的几何约束和接触动力学。为弥合这一差距，我们提出了 Ada-BFM，一种将预训练 BFM 适配于人形场景交互的后训练框架。Ada-BFM 通过轻量级适配器增强原始架构，在利用预训练控制能力的同时实现面向交互的特定调整。该框架不为每个任务生成单独控制器，而是为每个交互域产生一个共享模型，支持涉及地形或物体交互的多样化任务。在仿真和真实世界中的大量实验表明，Ada-BFM 能够实现多样化的场景交互行为，相比从零开始训练加速学习，并在很大程度上保留预训练的行为能力。这些发现确立了 Ada-BFM 作为一种有效且高效的方法，可将 BFM 的能力扩展到其预训练设置之外，同时保留其在通用全身控制方面的优势。

## Abstract
Behavior Foundation Models (BFMs) have emerged as a promising paradigm for general-purpose humanoid control through pretraining on large-scale behavioral data. However, their proficiency in whole-body coordination does not readily extend to scene interaction, which requires adapting motion to scene-dependent geometric constraints and contact dynamics. To bridge this gap, we introduce Ada-BFM, a post-training framework that adapts pretrained BFMs for humanoid scene interaction. Ada-BFM augments the original architecture with a lightweight adapter, enabling interaction-specific adjustments while leveraging pretrained control capabilities. Rather than producing a separate controller for each task, the framework yields a shared model for each interaction domain, supporting diverse tasks involving terrain or object interaction. Extensive experiments in simulation and the real world demonstrate that Ada-BFM enables diverse scene interaction behaviors, accelerates learning compared with training from scratch, and largely preserves pretrained behavioral competence. These findings establish Ada-BFM as an effective and efficient approach to extending the capabilities of BFMs beyond their pretraining settings while retaining their strengths in general whole-body control.

## 1. 核心问题与研究背景

- **背景**：人形机器人全身控制近年进展显著，但主流方法依赖针对具体任务的大量奖励工程，泛化性差。行为基础模型（Behavior Foundation Models, BFMs）通过在大规模人体动作数据上做“运动跟踪”式预训练，获得通用、可复用的全身协调控制能力，并随预训练规模扩大而持续提升。
- **核心问题**：现有 BFM 预训练基本是**场景无关（scene-agnostic）**的——主要基于平地数据，只关心“是否复现给定行为指令”，不考虑环境几何与接触动力学。而场景交互（上/下楼梯、跨台阶、搬箱、推箱、踢箱等）要求把动作**适配到场景相关的几何约束与接触动力学**上。
- **关键洞察**：丰富的动作库本身不等于场景交互能力，但预训练的行为知识可作为高效迁移的基础。因此问题转化为：**如何在不破坏预训练通用控制能力的前提下，把 BFM 扩展到场景交互？**
- **三重设计目标**：
  - **有效性（Effectiveness）**：每个交互域用**一个共享模型**覆盖多任务，并优于基线；
  - **效率（Efficiency）**：利用预训练行为知识加速场景交互能力习得（对比从零训练）；
  - **保持性（Retention）**：尽量保留预训练模型的原有广谱运动控制能力。

## 2. 方法论

### 2.1 核心思想

- 采用**后训练（post-training）适配**范式：**冻结**预训练 BFM 主干（Humanoid Transformer），仅新增一条**可训练的“场景通路”**（深度编码器 + 场景 tokenizer + 门控适配器），把场景观测作为**独立条件通路**注入，而非与原始运动指令简单拼接，以最小化对预训练控制能力的干扰。
- 每个交互域（地形 / 物体）只训练**一套共享参数 ϕₖ**，覆盖该域内多任务，而非逐任务单独建模。

### 2.2 问题形式化

- 行为定义为控制轨迹：B ≡ (s⁰ₚ, a₀, s¹ₚ, a₁, …, s^Tₚ)。
- 预训练控制器：π_θ₀(aₜ | Hₜ, Gₜ)，Hₜ 为本体感受-动作历史，Gₜ 为相对机器人根坐标系的未来全身目标。
- 每个交互域 k 建模为独立 MDP：Mₖ = ⟨Sₖ, A, Tₖ, Rₖ, γ⟩（共享动作空间与折扣因子）。
- 适配后策略：π_{θ₀,ϕₖ}(aₜ | Hₜ, Gₜ, oᵏₜ)，其中 oᵏₜ 为场景观测（深度图）。
- 优化目标：固定 θ₀，仅最大化域内期望折扣交互回报 max_{ϕₖ} E[Σ_{t=0}^{T−1} γᵗ rᵏₜ]。

### 2.3 学习范式

- **以运动为引导的交互目标**：
  - 地形域：rᵗᵉʳʳᵃⁱⁿₜ = r^BFMₜ（沿用原 BFM 的全身轨迹跟踪奖励，含根运动 + 身体姿态的稠密监督）；
  - 物体域：r^objectₜ = r^BFMₜ + r^taskₜ（额外加入物体位置、物体朝向、接触一致性等任务奖励）。
- **策略优化**：PPO，目标为 L = L_clip + c_v·L_value − c_e·H[π]（裁剪代理损失 + 裁剪值回归 + 熵正则）。
- **自适应采样**：按训练中观测到的失败次数把参考动作切成时间区间，失败多的区间被更高频采样，区间内均匀采起始帧，并保留均匀采样成分以维持覆盖。
- **非对称 Actor–Critic**：Actor 仅用本体感受历史 + 运动目标 + 深度；Critic 额外获得仿真特权信息（全身状态、地形/物体真值），部署时不需要。

### 2.4 网络结构细节

- **冻结部分**：预训练 tokenizer、初始 query embedding、所有 Transformer 块、动作头。主干以自注意力处理历史 token，以交叉注意力注入运动目标，末端 query token 聚合信息并预测动作（注意力掩码使 query 可读上下文、上下文不可读 query）。
- **场景表示**：自视角深度图 → 可训练 CNN 编码器 → 线性 tokenizer → 场景表示 zₜ。深度预处理：4 帧缓冲、随机时延偏移 {0,1,2,3} 模拟传感延迟、每边裁剪 2 像素、双线性缩放至 18×32、深度裁剪至 [0, 2.5] m 并归一化到 [0,1]。
- **门控适配器**（仅插入**最后一个 Transformer 块**中，位于参考交叉注意力之后、原 FFN 之前；只更新 query token，上下文 token 走原路径）：
  - 门控交叉注意力：h̃ₜ = hₜ + tanh(α)·Attn(N_h(hₜ), N_z(zₜ))（query 来自 hₜ，key/value 来自场景 zₜ）；
  - 门控前馈：h′ₜ = h̃ₜ + tanh(β)·FFN_adapt(N_f(h̃ₜ))，FFN 为 SwiGLU；
  - **门控标量 α、β 初始化为 0**，使适配分支初始输出为零，训练从“预训练动作均值”出发，保证平稳起步。
- **可训练参数**：深度编码器、场景 tokenizer、适配器；其余全部冻结。

## 6. 主要结论与发现

- **有效性**：单一共享模型即可覆盖域内多任务，并在两个域上取得最高成功率（地形 0.9914，物体 0.6575）。地形域在所有跟踪指标上最优（G-MPKPE 0.042 vs LoRA 0.060、Task Tokens 0.090）；物体域身体误差非全面最优，但物体位置/旋转误差最低（0.243 / 0.745 vs Task Tokens 0.448 / 1.006）。
- **仅跟踪身体不够**：ScaleBFM/SONIC 能较好跟踪身体，却在物体位置与朝向上误差大，说明物体交互需要超出运动跟踪的额外能力。
- **效率**：预训练先验显著加速学习并提升最终回报；从零训练成功率仅 0.0041（地形）/ 0.1151（物体），小预训练模型为 0.7819 / 0.4164，Ada-BFM 为 0.9914 / 0.6575。机制解释是预训练复用了运动控制能力，早期因身体位置误差导致的终止显著更少。
- **预训练越强越好**：更大容量、更多样动作数据预训练的 BFM 提供更强基础。
- **域间差异**：地形交互与预训练目标（运动跟踪）高度一致，因此提升更大、保持性更好；物体交互引入超出跟踪的需求，需要更多探索，收敛更慢、保持性略弱。
- **保持性**：BONES 上地形适配仅下降 0.028（0.944），物体适配下降 0.079（0.893），而全量微调、Head-only、LoRA、ViBe 下降更大（LoRA 物体适配降至 0.351）。这支持“冻结主干 + 独立条件通路”优于“改动主干权重”。
- **保持性结构**：手势、交流、物体操作、基础运动风格保持良好；Dancing 中度退化；退化最大的是 Stunts 与 Unusual Locomotion（翻转、翻滚、爬行），原因可能是适配数据覆盖少、异常姿态下视觉观测分布变化。
- **深度作用**：物体域对深度极敏感（zero-depth 成功率从 0.6575 降至 0.4685）；地形域总体成功率差异很小（0.9898），但深度主要改善**误差分布尾部**（p99 从 0.728 m 降至 0.426 m）与平均峰值误差（5.9%–9.9%），并在场景偏移下显著降低 p90（1.547 m → 0.589 m）。
- **鲁棒性边界**：中等场景位姿不匹配可被吸收，但偏移增大后成功率明显下降（地形 0.9914→0.8681，物体 0.6575→0.3436），说明方法仍以参考动作为强先验。

## 7. 优点

- **问题定位清晰**：准确指出 BFM “场景无关”这一结构性缺口，并把它转化为后训练适配问题，而非重新设计控制器。
- **架构设计克制且安全**：冻结主干 + 单块适配器 + 零初始化门控，使适配从恒等映射出发，天然兼顾“学新能力”与“不破坏旧能力”；只用一条独立条件通路，避免与运动指令耦合。
- **一域一模型**：以共享模型替代逐任务控制器，显著提升工程可扩展性，符合基础模型的复用理念。
- **统一表征**：地形与物体两域共用深度图作为场景表征、共用同一适配框架，仅替换环境与奖励，体现框架的域通用性。
- **实验体系完整且有自省性**：同时评估有效性、效率、保持性三条主线；引入 BONES 第三方基准量化“能力遗忘”；主动报告不占优的指标并分析域间差异成因。
- **细节工程扎实**：非对称 Actor–Critic、自适应失败采样、深度延迟/噪声/零值块/相机外参随机化、物体尺寸质量摩擦随机化，均有利于 sim-to-real。
- **真实机器人验证覆盖面广**：楼梯、坡道、路沿、越障、搬箱转身、不同形状材质重量物体、推/踢箱，并展示踩空后恢复能力。

## 8. 不足与局限

- **物体交互性能仍有限**：物体域成功率仅约 0.66，明显低于地形域，说明物体操作尚未真正“解决”；作者亦承认其需求超出运动跟踪先验。
- **数据覆盖偏窄**：物体域仅使用 OMOMO 中 largebox 一类物体，泛化到多样物体类别、铰接物体、精细操作（抓握、装配）未验证；训练/测试划分也来自同一子集，存在分布偏乐观风险。
- **强依赖参考运动**：所有任务都以参考轨迹 + 全身目标为条件，本质是“场景自适应的跟踪”，并非自主任务规划或目标驱动交互；场景偏移增大即明显退化。
- **适配容量受限且未探索**：仅适配最后一个 Transformer 块；未报告适配更多层、增大适配器容量或与 LoRA 组合的效果，也未给出参数量/推理开销对比。
- **保持性仍有可感退化**：Stunts、Unusual Locomotion 等类别退化较大，说明“保持”并非无损；作者归因于数据覆盖与视角分布变化，但未做针对性缓解实验。
- **实机评估为定性**：真实世界仅展示成功案例视频，缺少成功率、重复次数、失败模式统计与定量对比；深度相机型号单一（RealSense D435i），未评估不同传感器或强光/弱纹理等极端条件。
- **成功判据较宽松**：全身最大位置误差 0.5 m 的阈值相对宽松，可能掩盖细粒度执行质量差异（附录用峰值误差分位数部分弥补）。
- **算力与成本信息不完整**：仅报告 Ada-BFM 自身训练时长，缺少基线训练成本、总计算量、推理时延与机载算力需求，难以评估实际部署代价。
- **奖励工程未完全消除**：物体域仍手工设计物体位置/朝向/接触一致性奖励与权重，与论文批评的“任务特定奖励工程”存在一定张力。
- **单一机器人平台**：仅在 Unitree G1 上验证，跨本体（不同自由度、尺寸、质量分布）迁移性未知。
