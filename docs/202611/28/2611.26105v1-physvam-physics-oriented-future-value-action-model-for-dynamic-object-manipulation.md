## 摘要
预测未来场景或物体状态并不一定能揭示机器人—物体交互将如何推进或阻碍任务。这一挑战在动态机器人操作中尤为突出，因为物体在感知和执行过程中会持续运动。因此，有效的动作生成不仅需要对物体动力学建模，还需要预判未来交互将如何影响任务进展。为此，我们提出 PhysVAM，一种面向物理的未来价值动作模型，通过预期交互对未来任务进展的影响来表示这些交互。这种基于价值的建模方式提供了任务导向的前瞻能力，而无需重建未来视觉状态。以当前观测以及历史物体和机器人运动为条件，PhysVAM 联合学习动作生成和多时间跨度未来价值预测。价值分支通过从成功和失败轨迹中进行未来任务价值预测，学习特定时间跨度的潜在表示。这些未来价值表示通过门控交叉注意力集成到动作策略中，引导动作生成朝向有助于任务成功的交互。大量仿真和真实世界实验表明任务成功率更优，在仿真和真实世界任务中，相较最强基线分别取得 27.0 和 27.5 个百分点的绝对成功率提升。项目页面：https://metarobo.github.io/physvam.github.io/。

## Abstract
Predicting future scene or object states does not necessarily reveal how robot-object interactions will advance or hinder a task. This challenge is particularly pronounced in dynamic robotic manipulation, where objects continue moving during perception and execution. Effective action generation therefore requires not only modeling object dynamics but also anticipating how future interactions will shape task progress. To this end, we propose \textbf{PhysVAM}, a Physics-oriented Future Value Action Model that represents anticipated interactions through their effects on future task progress. This value-based formulation provides task-directed foresight without reconstructing future visual states. Conditioned on current observations and historical object and robot motion, PhysVAM jointly learns action generation and multi-horizon future-value prediction. The value branch learns horizon-specific latent representations through future task-value prediction from successful and failed trajectories. These future-value representations are integrated into the action policy through gated cross-attention, guiding action generation toward interactions that facilitate task success. Extensive simulation and real-world experiments demonstrate superior task success, with absolute success-rate improvements of 27.0 and 27.5 percentage points over the strongest baselines in simulation and real-world tasks, respectively.
