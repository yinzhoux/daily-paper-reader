## 摘要
基于模型的强化学习（MBRL）能够通过想象经验改进预训练的视觉-语言-动作（VLA）策略。然而，现有的VLA-MBRL方法主要依赖大规模图像或视频生成世界模型，带来较大的计算开销。潜在世界模型提供了更高效的替代方案，但面临两个挑战：递归预测过程中的误差累积，以及与VLA视觉输入接口不兼容。本文提出LS-MBPO，一种轻量级残差MBRL框架，利用潜在世界模型改进预训练VLA。LS-MBPO引入两项关键技术：（1）分层强制（Hierarchical Forcing），将稠密因果监督与自回归反馈相结合，以缓解累积预测误差；（2）潜在子块展开（Latent Subchunk Rollouts），利用来自冻结VLA策略的动作块和潜在残差策略进行连续的子块细化，弥合潜在想象与VLA策略执行之间的差距。我们进一步引入进度条件分支起始课程（Progress-Conditioned Branch-Start Curriculum），逐步将展开起始点从任务后期阶段移到早期阶段，从而能够从短时想象展开中有效学习策略。在LIBERO、RoboTwin和真实世界ALOHA机器人上的大量实验表明，与现有方法相比，LS-MBPO取得了更优的任务性能和训练效率。

## Abstract
Model-based reinforcement learning (MBRL) can improve pretrained vision-language-action (VLA) policies through imagined experiences. However, existing VLA-MBRL methods primarily rely on large-scale image or video generation world models, incurring large computational overhead. Latent world models offer a more efficient alternative but face two challenges: compounding errors during recursive prediction and incompatibility with VLAs' visual input interfaces. In this work, we propose LS-MBPO, a lightweight residual MBRL framework that leverages latent world models to improve upon pretrained VLAs. LS-MBPO introduces two key techniques: (1) Hierarchical Forcing, which combines dense causal supervision with autoregressive feedback to mitigate compounding prediction errors; and (2) Latent Subchunk Rollouts, which leverage action chunks from a frozen VLA policy and a latent residual policy for successive subchunk refinement, bridging the gap between latent imagination and VLA policy execution. We further introduce a Progress-Conditioned Branch-Start Curriculum that progressively shifts rollout starting points from later to earlier task stages, enabling effective policy learning from short imagined rollouts. Extensive experiments on LIBERO, RoboTwin, and a real-world ALOHA robot show that LS-MBPO achieves superior task performance and training efficiency compared to existing methods.

## 1. 核心问题与研究动机

- **背景**：基于模型的强化学习（MBRL）能够借助“想象经验”改进预训练的视觉-语言-动作（VLA）策略，从而减少对昂贵真实交互的依赖。
- **现有路线的问题**：当前 VLA-MBRL（如 WMPO、VLA-MBPO、U-GROW）主要依赖**像素级大规模图像/视频生成世界模型**，需在想象展开中生成高维视觉观测，计算与显存开销巨大；而且像素级预测未必给出最适合下游策略学习的紧凑状态表示。
- **潜在世界模型的吸引力与两大障碍**：
  1. **递归预测的复合误差（compounding error）**：现有潜在动力学模型多用“单步预测 + 真值历史（teacher forcing）”训练，但推理时须把自己的预测作为输入，训练/推理条件不一致，误差会逐步放大。
  2. **接口不匹配**：潜在世界模型在紧凑隐空间预测未来状态，而预训练 VLA 需要视觉观测作为输入，隐状态无法直接喂给 VLA；若采用“全参数微调 VLA”又会带来巨大的计算与显存负担，抵消潜在模型的效率优势。
- **核心研究问题**：如何在保证递归预测可靠性与策略优化计算效率的前提下，把潜在想象用于 VLA 的强化学习？

## 2. 方法论：LS-MBPO 框架

### 2.1 总体思想

- 提出 **LS-MBPO（Latent Subchunk Rollout for MBPO）**：一个轻量级**残差式** MBRL 框架——冻结预训练 VLA 提供行为先验，只训练一个轻量潜在残差策略与价值网络，在潜在世界模型中进行“子块级”想象展开与 TD3+BC 优化。
- 输入设定：离线数据集 `D`（训练世界模型）＋ 小规模专家数据集 `G`（训练成功检测器、进度预测器）。

### 2.2 关键技术一：分层强制（Hierarchical Forcing）训练潜在世界模型

- **多视角编码**：对 m 个相机视角分别用共享 ViT 编码，取各视角 [CLS] token 特征拼接为联合隐表示 `z_t = Concat_k E_θ(I_t^k)`。
- **动作条件动力学预测器** `F_ϕ`：采用**因果注意力**，保证每个位置只能关注当前及之前的隐状态，从而可在窗口内每个位置同时做“下一帧”预测；帧间隔（frame skip）为 `h`，窗口长度 `K`。
- **递归窗口训练流程**：
  - 初始窗口 `W_0` 由 K 个连续真值隐状态组成；
  - 第 r 步用当前窗口 `W_r` 与动作条件 `U_r` 预测窗口内所有位置的下一帧隐状态 `Ŷ_r`；
  - 随着递归推进，输入窗口逐步由“全真值”过渡到“全预测值”（r+i < K 用真值，否则用先前预测），使预测器逐步适应推理时的自回归输入条件。
- **稠密监督损失**：对 R 个递归步 × K 个窗口位置的预测全部与真值隐状态做 L2 监督：
  `L_pred = (1/RK) Σ_r Σ_i || Ŷ_r[i] − z_{t+(r+i+1)h} ||²`（区别于 Recursive-only 仅监督窗口末位）。
- **辅助正则**：SIGReg 防止表示坍缩；CNN 解码器做多视角图像重建损失 `L_img`（仅为保留视觉信息，不用于策略学习）；附录还加入本体感知（proprioception）预测解码器。总目标：`L_WM = L_pred + λ_reg·L_SIGReg + λ_img·L_img`。

### 2.3 关键技术二：潜在子块展开（Latent Subchunk Rollouts）

- **动机**：绕开“隐状态 ↔ 视觉输入”的接口不匹配，且避免全参数微调 VLA。
- **流程**：
  1. 在分支起点用**冻结 VLA** 生成一次长度为 H 的基础动作块 `B_t = π_VLA(o_t, ℓ)`；
  2. 将其切分为 N 个长度 h 的子块（H = Nh），第 j 个子块记为 `B_t^(j)`；
  3. 残差策略以“当前潜在状态 + 对应基础子块 + 语言指令”为输入输出动作修正：`ΔA_j ~ π_ψ(·| ẑ_{t+jh}, B_t^(j), ℓ)`；
  4. 修正动作子块 `Ã_j = clip(B_t^(j) + β·ΔA_j, A_min, A_max)`（β 控制修正幅度）；
  5. 把修正子块送入潜在世界模型，预测下一子块时刻的隐状态 `ẑ_{t+(j+1)h}`（取输出窗口末位），再用于下一步残差决策，形成闭环。
- **关键收益**：**一次 VLA 查询可支撑多次（N 个）残差决策**，想象展开期间无需重查或更新 VLA。

### 2.4 奖励与策略优化

- **成功检测器** `ξ(z_t, ℓ)`：用 `G` 中每条轨迹末尾 n₁ 帧为正样本、`G` 与 `D` 中末尾 n₂ 帧之前的帧为负样本训练；想象中对每个子块后的预测隐状态给出二值奖励 `r̂_j = 1[ξ(ẑ_{t+(j+1)h}, ℓ) ≥ τ]`。
- **策略优化**：TD3 + BC。双 critic 输入 `(x_j, Ã_j)`（x_j 为隐状态、本体感知、语言嵌入的拼接），用 TD 目标回归；动作上加 BC 正则项 `L_BC = E[MSE(Ã_ψ, B_t^(j))/β²]` 锚定冻结 VLA 的参考子块；想象边界处（最后一个子块）令终止标志 d_{N−1}=1，退化为仅用即时奖励 `y_{N−1} = r̂_{N−1}`。

### 2.5 关键技术三：进度条件分支起始课程（PBC）

- 用专家数据 `G` 训练进度预测器 `g_p(z_t, ℓ) → p̂_t`，**仅用于分支起点采样，不用作奖励**。
- 构造随训练轮次 e 演化的采样分布 `P_e(i) = w_e(p̂_i) / Σ_j w_e(p̂_j)`：早期偏向高进度（后期阶段）状态，使短展开更易到达成功并给出正样本；随训练推进逐步扩展到低进度（早期阶段）状态。
- 明确论证“不用进度作奖励”的理由：进度预测器只在专家分布上训练，对策略探索出的分布外状态估计不可靠，作稠密奖励易被“刷分”；而起点采样只需粗粒度阶段信息，容忍误差。

- **PBC 有效且优于固定策略**：均匀采样 54.4%、固定后期采样 64.8%、PBC 71.2%——说明“先后期、再前移”的课程安排优于任一静态方案。
- **二值奖励优于进度奖励**：进度奖励（单独或与二值混合）表现不佳，归因于进度预测器在分布外状态上的泛化不足与奖励被“刷分”风险。
- **VLA 先验不可或缺**：无 VLA 先验的潜在策略仅 22.4%（加 BC 正则 41.6%），远低于 71.2%。

  - 潜在子块展开巧妙地把“接口不匹配”转化为“残差修正”问题，同时顺带解决了全参数微调的开销问题。
- **工程与算法协同设计良好**：冻结 VLA + 轻量残差 + 单次查询多用，使得 RL 阶段可在**单张消费级/工作站级 GPU** 上完成，实用性强。
- **PBC 的设计体现了对奖励设计的清醒认识**：明确区分“可用于采样的粗粒度信号”与“不可用于奖励的不可靠信号”，避免 reward hacking，这一讨论具有方法论价值。
- **实验对照规范**：基线共享同一底座与同一“冻结 + 残差”范式，并对在线 RL 对齐交互预算，公平性考虑到位；同时给出 PSNR 与成功率双证据链，并附长程展开可视化。

## 8. 不足与局限

- **世界模型能力边界**：仍依赖辅助图像解码器与重建损失（虽仅作正则），且想象展开长度受限（L = 50 步、单次 VLA 动作块内），作者自认尚不能支持**全时域长程展开**。
- **奖励信号单薄**：仅用二值成功检测器，奖励稀疏；成功检测器的正负样本构造依赖“轨迹末 n₁ 帧即成功”的启发式假设，在长程/多阶段任务上可能标注偏差。作者也把“更具泛化性的隐空间稠密奖励模型”列为未来工作。
- **进度预测器的泛化风险**：仅在小规模专家数据上训练，虽然本文只用于采样，但 PBC 的效果仍隐含依赖其粗略排序的正确性；跨任务/跨具身时该假设可能失效。
- **实验覆盖与统计严谨性不足**：
  - 消融几乎集中在 LIBERO Long 单任务，泛化性证据有限；
  - 未报告多次运行的均值±方差、未说明种子数量，主表小幅度提升（如 71.2 vs 69.6）的显著性存疑；
  - 真实世界仅 2 个任务、每任务 20 次评测、单一机器人平台，且任务相对短程、结构化；
  - 与像素级 SOTA 的比较仅限 VLA-MBPO 的单一子集单点结果，缺少与 U-GROW、WMPO 等的全面对比。
- **指标代理性问题**：用解码图像的 PSNR 衡量潜在世界模型质量只是间接代理，且作者自己指出重建视觉保真度有限；PSNR 与策略性能之间并非严格单调对应。
- **超参与基准适配**：h = 5、H = 50、L = 50、β、τ、n₁/n₂ 等关键超参在全部任务上统一设置，未讨论敏感性，存在针对 benchmark 调优的隐忧。
- **应用限制**：方法假设存在预训练 VLA、离线数据集与少量专家示范三者齐备；残差修正幅度受 β 与 clip 约束，若基础 VLA 先验在目标任务上严重失配（如跨具身迁移），残差策略可能难以弥补。
- **声明性表述**：“首个将 VLA 与潜在世界模型结合做 MBRL”的断言缺乏系统性文献对比支撑，需谨慎看待。
